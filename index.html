How to Grab Your tautulli.db
Tautulli stores all of your Plexamp listening history inside a single SQLite file named tautulli.db:
• Docker: inside Tautulli’s /config/tautulli.db volume.
• macOS: ~/Library/Application Support/Tautulli/tautulli.db
• Windows: %LocalAppData%\Tautulli\tautulli.db
• Tautulli UI check: Open Tautulli → Settings → Help & Info to see the exact Database File path on your machine.
Fastest way to host a one-time download link on your LAN:
cd /path/to/tautulli-config python3 -m http.server 8099
Then switch back to ⚙️ Connect & Settings, paste http://YOUR-SERVER-IP:8099/tautulli.db, click Fetch DB Link, and press Ctrl+C to stop the temporary server. Or simply pick the file under Option B — Upload File.
How to Grab Your X-Plex-Token
1. Open Plex Web and play or open any track in your Music library.
2. Click the ⋯ (More) menu → Get Info → View XML.
3. Look at the browser URL bar — copy the token at the end after X-Plex-Token=.
4. Paste your Plex URL and token into Tab 1 and hit 🔍 Test & Auto-Detect — Rotation automatically fills in your Machine ID, Server Name, and Music Library ID.
How to Install With Docker Compose or Python
cp .env.example .env # Optional: edit .env to mount your Tautulli folder or set APP_PASSWORD docker compose up -d --build # Open http://localhost:8888
Sharing online safely: Set a passcode in Tab 1 (or APP_PASSWORD in .env) before exposing Rotation through Tailscale Funnel, Cloudflare Tunnel, or a reverse proxy. No personal info or keys live inside the repository — everything stays in cache/ (gitignored).
